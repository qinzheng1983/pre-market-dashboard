敞口方向确认

韩国子公司需要向母公司/供应商支付人民币货款 → 子公司持有韩元，需购汇人民币（卖出KRW，买入CNY）。

汇率影响：韩元升值（KRW走强）→ 同样多韩元可换更多人民币 → 子公司支付成本降低 → 对我司有利；

韩元贬值（KRW走弱）→ 需更多韩元才能换到同样人民币 → 子公司支付成本增加 → 对我司不利。

CNY/KRW标价解读：1 CNY = X KRW。CNY/KRW数值下降 → 韩元升值 → 对我司有利；CNY/KRW数值上升 → 韩元贬值 → 对我司不利。

敞口性质：韩国子公司需支付CNY，汇率风险在于韩元走弱（KRW depreciation）。

1.2 自我挑战（每个因子）

因子一：中韩利差 — 模型假设与反逻辑挑战

模型假设：韩国10Y国债收益率（4.34%）显著高于中国10Y（1.68%），中韩利差+266BP。BOK 7月16日加息25BP至2.75%，8月28日大概率再加息25BP至3.00%，而中国央行维持宽松（10Y在1.6-1.7%低位），中韩利差可能进一步拉宽 → 韩元升值（CNY/KRW下降）→ 对我司有利。

反逻辑挑战：7月前的历史经验显示，利差拉宽并未推动韩元升值——2026年上半年韩国10Y从3.75%升至4.19%，但韩元反而贬值（USD/KRW从~1400升至~1555）。原因是资本外流（外资抛售韩股~1000亿美元）完全压倒了利差支撑。但7月后情况发生质变：BOK实际加息+SK海力士结汇+出口商抛售美元，利差终于传导至汇率。

历史失败案例：2026年1-6月，利差持续拉宽但韩元贬值，证明利差单独不足以支撑汇率。需配合资本流动方向。

重定价阈值：若中国10Y因财政刺激反弹至2.0%+，或BOK暂停加息，利差拉宽速度放缓，韩元升值动能减弱。

当前推断：【主导】BOK 7月已加息，8月再加息概率高，利差拉宽趋势明确。7月后资本外流放缓（SK海力士结汇+企业抛售美元），利差因子终于主导汇率。

因子二：半导体周期 — 模型假设与反逻辑挑战

模型假设：AI芯片超级周期 → 韩国出口暴增 → 贸易顺差扩大 → 企业结汇 → 韩元升值。

反逻辑挑战：2026年上半年韩国贸易顺差创历史高位（1-6月1383亿美元），但韩元反而跌至2009年来最低（USD/KRW 1560）。BOK 4月报告指出"贸易顺差不再支撑弱势韩元"——资本外流完全抵消了顺差支撑。但7月后发生质变：SK海力士ADR上市融资265亿美元并持续结汇，直接推动韩元走强。此外，半导体企业密集公布本土大额资本开支计划，需将美元营收兑换为韩元，形成真实结汇需求。

历史失败案例：2026年1-6月，出口增长34%-70%，但韩元贬值3.8%，为表现最差亚洲货币之一。关键差异：上半年企业留存海外美元，下半年开始结汇。

重定价阈值：若AI投资周期见顶或半导体需求骤降，顺差可能快速收窄。但当前AI资本开支仍在加速。

当前推断：【主导】7月后顺差终于转化为汇率支撑。SK海力士结汇265亿美元是触发点，形成连锁效应（其他企业跟进抛售美元）。8月前20天出口同比+56%，基本面支撑强劲。

因子三：政策与风险溢价 — 模型假设与反逻辑挑战

模型假设：BOK鹰派连续加息 → 韩元升值；美联储9月降息 → 美元走弱 → 韩元被动升值。

反逻辑挑战：美联储7月FOMC维持不变，但9月降息预期升温（市场押注降息25-50BP）。若美联储9月降息而BOK 8月再加息，韩美利差大幅收窄 → 韩元强势。但若美联储意外鹰派或朝鲜半岛风险升级，风险溢价可能飙升。

历史失败案例：2025年8月美联储降息预期升温，但BOK因韩美息差创历史新高而被迫冻息，韩元仍贬值。当前情况不同：BOK已主动加息，政策路径独立。

重定价阈值：若朝鲜半岛地缘风险升级（朝鲜核试验/导弹试射）或韩美防卫费谈判破裂，风险溢价可能飙升。

当前推断：【支撑】BOK 8月28日再加息25BP概率高（5/7家券商预测），美联储9月降息预期升温。政策分化有利于韩元。
