三、周度洞察层
3.1 本周特征提炼
本周市场呈现"油价暴涨、美元走强、人民币微升、商品分化"的四重格局。布伦特原油周涨13%突破109美元，创3月以来最大周涨幅，直接导火索是伊朗9月6日宣布霍尔木兹"禁区"及美伊海上军事摩擦。美元指数同步走强至99.1，10年期美债收益率创2023年11月以来新高。人民币中间价小幅升值52基点，但在美元强势背景下升值空间受限。商品市场分化明显：铜创历史新高后回落，碳酸锂暴跌近10%，镍价窄幅波动。
3.2 汇率市场：央行的"逆周期调节"而非"刚性锚定"
本周USD/CNY中间价6.7795→6.7743，人民币升值52基点，但即期汇率与中间价维持窄幅贴水，显示市场力量与央行引导基本平衡。

关键辨析：中间价贴水扩大≠央行引导有序贬值。根据央行中间价报价模型（收盘价+一篮子货币汇率变化+逆周期因子），逆周期因子的核心功能是平抑市场情绪的顺周期波动，而非锚定某个固定汇率。本周人民币升值发生在美元走强（DXY 99.1）的背景下，说明逆周期因子可能在发挥"防范过度升值"的作用——当美元对全球货币普遍走强时，人民币相对美元反而微升，这背后是央行通过逆周期因子调节，避免人民币跟随美元对非美货币过度升值，从而维持一篮子货币汇率的基本稳定。

对我司影响：中间价管理降低了USD/CNY大幅双向波动风险，但不意味着汇率被"锁定"。本周人民币升值对集团资本层面12亿美元Long USD敞口不利（子公司美元负债折算膨胀）。在美元强势周期中，人民币升值空间受限，但短期波动仍需警惕。

3.4 推演与情景分析
基准情景（55%）：美伊和谈继续拉锯，霍尔木兹维持"准关闭"状态
触发条件：双方无重大突破也无系统性冲突升级，特朗普"中选后结束战事"言论部分兑现
→ Brent维持在105-115美元高位震荡；美元指数在98-100区间波动；USD/CNY在6.75-6.82区间窄幅波动。
→ 对我司影响：能源成本维持高位，资本层面12亿美元Long USD敞口在美元强势中获得部分保护，但人民币升值风险仍在。建议维持现有套保比例，重点监控美联储决议。
乐观情景（20%）：美伊签署阶段性协议，霍尔木兹通航恢复
触发条件：9月中下旬在巴基斯坦/卡塔尔斡旋下达成临时停火或通航安排
→ Brent快速回落至95-100美元；市场风险偏好回升，美元走弱；人民币被动升值压力减轻。
→ 对我司影响：能源成本下降，但资本层面Long USD敞口将承受美元贬值带来的负债折算膨胀。需提前评估是否增加美元负债的对冲覆盖。
悲观情景（25%）：谈判破裂，冲突升级为系统性军事对抗
触发条件：伊朗铀浓缩丰度提升至95%，或美军对伊朗核设施实施打击
→ Brent突破120美元，全球通胀失控；美联储被迫加速加息；美元飙升；非美货币包括人民币承压。
→ 对我司影响：资本层面12亿美元Long USD敞口将受益（美元暴涨→负债折算大幅减少），但欧洲/日韩/印尼业务的非美货币敞口将承压。需紧急评估多币种敞口净效应。
